# 神经多样性特质自筛量表（shenduo-scale）- 产品需求文档

## Overview
- **Summary**: 实现"神经多样性特质自筛量表"（趣味版，别名"神多特质趣味筛查"）：汪星人（ADHD 特质）、喵星人（ASD 特质）、敏感星人（HSP 特质）三大部分各 20 题、共 60 题二选一作答，按部分独立计分，结果页以"三颗星人比例卡 + 组合解读 + 高分建议 + 附录资源"呈现趣味 H5 报告。
- **Purpose**: 帮助青少年及成人探索自身大脑独特的"出厂设置"，了解自身注意力模式、社交偏好与感官敏感度的天然组合，做神经多样性科普与自我探索参考。
- **Target Users**:
  - 普通用户（青少年及成人，自评）
  - 后台管理员（仅只读 + 启停）

## Goals
- 实现用户端完整流程：使用说明 → 三部分顺序答题（每部分 20 题二选一）→ 结果报告
- 按原始 PDF 逐题整理 60 题数据并经脚本幂等入库
- 计分与分级规则 100% 准确（每部分得分 ÷20 = 占比；0-5 不明显 / 6-10 轻度存在 / 11-15 较为突出 / 16-20 非常显著）
- 结果页以趣味配色（🐕 琥珀 / 🐱 青绿 / 🌸 玫红）+ 比例进度条 + 组合解读呈现
- 后台对 shenduo-scale 只读（数据由导入脚本维护）

## Non-Goals (Out of Scope)
- 不做多档选项（仅二选一：符合/不符合，与原始 PDF 一致）
- 不做结果报告导出/打印（H5 网页展示即可）
- 不做后台题目编辑（只读 + 启停）
- 不涉及医学诊断声明（仅科普参考，结果页含免责声明）
- 不拆分 3 个独立量表（已确认单量表 3 部分形态）

- 题目内容改编参考：汪星人部分参考 WHO 成人 ADHD 自筛量表（ASRS）核心维度；喵星人部分参考 AQ 量表与 RAADS-R 设计；敏感星人部分参考 Elaine Aron 的 HSP 量表设计（均为"简化二选一"改编，非原表原文）。

## 量表规则（来自原始 PDF）

### 作答方式
- 三大部分按顺序作答，每部分 20 题，总计 60 题，约 10-15 分钟。
- 每题两个选项：「符合」（得 1 分）或「不符合」（得 0 分），无"有时"选项；犹豫时选更接近日常状态的一项。
- 以近 6 个月以来的真实感受为准。

### 计分与分级
- 每部分满分 20 分，得分 ÷20 = 该特质占比（百分比 = 得分 × 5%）。
- 分级（二选一计分产生非连续百分比，区间沿用 PDF 原文）：

| 得分 | 占比 | 分级 |
|---|---|---|
| 0-5 | 0%-25% | 不明显 |
| 6-10 | 30%-50% | 轻度存在 |
| 11-15 | 55%-75% | 较为突出 |
| 16-20 | 80%-100% | 非常显著 |

- 三种特质可以同时共存（总分 = 三部分得分之和，0-60，仅作展示）。

### 结果解读（结果页）
- 三张特质比例卡：emoji + 特质名 + 得分/20 + 百分比 + 分级徽章 + 彩色进度条 + 各特质解读。
- 组合解读（当两个特质得分均 ≥6 时展示，阈值为本项目设计决策）：
  - 汪星人 + 喵星人 = 「思维活跃但社交独特」
  - 喵星人 + 敏感星人 = 「深度观察者型」
  - 汪星人 + 敏感星人 = 「热情但容易内耗」
- 高分建议：得分 ≥6 的特质展示对应建议清单（番茄工作法 / 社交能量配额 / 无刺激时间等）。
- 附录资源：推荐阅读（4 本）+ 专业求助渠道（4 项）+ 免责声明。

### 面向用户文案（使用说明页）
- 什么是神经多样性、三特质介绍、如何作答、评分与结果解读表、重要提示（仅供科普参考，不构成医学诊断）。

## 设计决策记录（实施确认）
- 量表 ID：`shenduo-scale`；分类「人格特质评估」（沿用现有分类口径）。
- 题目数据以 TS 常量文件（`src/lib/shenduo-questions.ts`）作为唯一数据源，导入脚本读取后入库，便于审计与幂等重导。
- 组合解读判定阈值取"双方得分 ≥6（轻度及以上）"，避免仅"较为突出"才展示导致多数用户看不到组合信息。
- 后端 key 兼容 UUID 与 `q{n}` 两种格式（与 CDMM 归一化思路一致）。
- 结果页/答题页配色沿用站点深色风格，三特质分别以琥珀/青绿/玫红区分。
