# CDMM 儿童发育里程碑核验系统 - 产品需求文档

## Overview
- **Summary**: 为"儿童发育里程碑核验"（CDMM）实现完整的量表功能：家长输入儿童信息后，系统按矫正月龄匹配 18 个月龄组问卷之一，按 8 大能区 + 警示标志分组作答，结果以"能区脚丫颜色（蓝/绿/黄）+ 警示红灯"呈现为 H5 报告。
- **Purpose**: 帮助家长/养育人监测 2 月龄~8 岁儿童发育里程碑是否步入正轨，发现可能的发育迟缓信号。
- **Target Users**:
  - 普通用户（家长、监护人等）
  - 后台管理员（仅只读 + 启停）

## Goals
- 实现 CDMM 用户端完整流程：儿童信息采集 → 矫正月龄匹配 → 分组答题 → 结果报告
- 实现 xlsx 数据自动解析入库（799 题，18 月龄组 × 8 能区 + 警示标志）
- 确保年龄匹配与计分规则 100% 准确（最高优先级）
- 结果页按 docx 样板样式呈现 H5 报告（彩虹脚丫图、发展目标里程碑、小红灯）

## Non-Goals (Out of Scope)
- 不提供结果报告导出/打印（H5 网页展示即可）
- 不做后台题目编辑（只读 + 启停）
- 不涉及用户管理、数据导出、高级数据分析（已有/不做）
- 不做 18 个独立量表形态（已确认单量表）

## 量表规则（来自规则文档）

### 月龄组匹配（按矫正月龄）
- 矫正月龄：足月按实际月龄；早产儿矫正到 40 周（预产期法）
- 区间（"月数×30+天数"归一化）：

|---|---|---|---|---|
| 2月龄 | 1月0天~2月30天 | | 24月龄 | 23月0天~29月30天 |
| 4月龄 | 3月0天~4月30天 | | 3岁 | 30月0天~41月30天 |
| 6月龄 | 5月0天~6月30天 | | 4岁 | 42月0天~53月30天 |
| 8月龄 | 7月0天~8月30天 | | 5岁 | 54月0天~65月30天 |
| 10月龄 | 9月0天~10月30天 | | 6岁 | 66月0天~77月30天 |
| 12月龄 | 11月0天~12月30天 | | 7岁 | 78月0天~89月30天 |
| 14月龄 | 13月0天~14月30天 | | 8岁 | 90月0天~101月30天 |

| 20月龄 | 19月0天~20月30天 | | | |
| 22月龄 | 21月0天~22月30天 | | | |

- 边界：矫正月龄 ≤ 0月30天（30 天）或 ≥ 102月0天（3060 天）→ 报错，不进入答题

### 8 大能区计分
- 均为单选题，选项：未做到 / 不熟练 / 很熟练
- 每能区独立计算：
  - 全部"很熟练" → 蓝色脚丫
  - 有"不熟练"且无"未做到" → 绿色脚丫
  - 只要有"未做到" → 黄色脚丫

### 警示标志计分
- 均为单选题，选项：有 / 没有
- 只要出现"有" → 红灯亮；全部"没有" → 不亮红灯
- 部分月龄组（8/14/16/20/22月龄、7岁、8岁）无警示标志数据 → 不产生警示题，不显示红灯区

## Functional Requirements

### FR-1: 儿童信息采集与年龄匹配
- 答题前展示信息表单：儿童姓名、性别、出生日期、是否早产（是 → 填预产期）
- 系统按矫正月龄匹配 18 个月龄组之一
- 矫正月龄超范围时给出明确报错，不进入答题

### FR-2: 分组答题
- 一屏展示一个能区的全部题目（里程碑题三选项单选）
- 顶部显示能区进度（如"粗大动作 1/8"）
- 警示标志作为最后一组（仅该月龄组有警示题时）
- 支持跨能区往返修改答案
- 全部答完后提交

### FR-3: 计分（最高优先级）
- 每能区输出蓝/绿/黄脚丫
- 警示输出红灯触发状态与命中明细
- 结果 details 包含：儿童信息、矫正月龄、能区颜色、红灯项、目标里程碑明细（未做到+不熟练）

### FR-4: 结果报告页（H5）
按 docx 样板结构展示：
- 报告标题"CDMM 儿童发育里程碑核验报告" + 儿童信息卡（姓名、性别、出生日期、完成筛查日期、筛查编号 CDMM+出生年月+日期+随机两位数、提供筛查机构）
- 8 能区彩虹脚丫图（含图例：未做到/不熟练/很熟练）
- 发展目标里程碑：按能区列出"未做到"与"不熟练"项目
- 小红灯区：命中警示项（红色卡片）；未命中显示"未发现红灯"
- 结束语与签字区（静态展示）

### FR-5: 数据自动导入
- 提供 xlsx 解析脚本：按 ◆ 拆分、清洗换行/空格/重复符号
- 生成校验报告（每月龄组题数、空警示区提示）
- 通过脚本入库（scales + questions）

### FR-6: 后台管理（只读 + 启停）
- 管理员可在后台查看 CDMM 量表信息与题目
- 可启用/禁用 CDMM 量表
- 不提供题目编辑

## Non-Functional Requirements

### NFR-1: 计分与年龄匹配准确性
- 年龄区间边界与计分规则必须经过充分测试，错误率为 0

### NFR-2: 用户体验
- 答题流程流畅直观，支持移动端（H5）
- 能区切换清晰，进度可见

### NFR-3: 数据完整性
- xlsx 导入结果可校验、可重复执行（幂等）

## Constraints
- **Technical**: 必须使用现有技术栈（Next.js 14 + SQLite + TS + Tailwind），遵循现有代码风格
- **Business**: 年龄区间、能区计分、警示规则必须与规则文档一致
- **Dependencies**: 依赖现有 scales/questions 表结构与答题/结果流程，questions 表需新增 meta 字段

## Assumptions
- xlsx 为权威数据源，导入后不再经后台修改
- "很熟练"项不出现在"发展目标里程碑"（仅列未做到/不熟练）
- 矫正月龄按"预产期 − 出生日期"的天数差做早产矫正

## Acceptance Criteria

### AC-1: 儿童信息与年龄匹配正确
- **Given**: 用户进入 CDMM 答题页
- **When**: 填写儿童信息（含早产场景）
- **Then**: 系统正确计算矫正月龄并匹配月龄组；超范围给出报错
- **Verification**: `programmatic`（边界测试用例）
- **Notes**: 覆盖 30/90/150…3060 天边界

### AC-2: 分组答题完整
- **Given**: 已匹配到月龄组
- **When**: 用户按能区作答并提交
- **Then**: 答案与儿童信息正确保存，跳转结果页
- **Verification**: `programmatic`

### AC-3: 计分规则 100% 准确
- **Given**: CDMM 已实现
- **When**: 运行计分测试用例
- **Then**: 蓝/绿/黄脚丫与红灯判定全部正确
- **Verification**: `programmatic`
- **Notes**: 覆盖全蓝、全绿、全黄、混合、红灯触发/不触发场景

### AC-4: 结果报告正确展示
- **Given**: 已完成 CDMM 测评
- **When**: 访问结果页
- **Then**: 展示彩虹脚丫图、发展目标里程碑、小红灯区，样式符合 docx 样板
- **Verification**: `human-judgment`

### AC-5: 数据导入正确
- **Given**: xlsx 解析脚本执行
- **When**: 完成导入
- **Then**: 799 题入库，每月龄组/能区题数与 xlsx 一致，无重复题
- **Verification**: `programmatic`

### AC-6: 后台只读 + 启停
- **Given**: 管理员登录后台
- **When**: 查看 CDMM / 切换启停
- **Then**: 可查看信息与题目，启停立即生效，无编辑入口
- **Verification**: `programmatic`
